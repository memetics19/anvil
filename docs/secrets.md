# Secrets in Vault

Secret values live only in Vault (KV v2, mount `kv`), at `kv/homelab/<host>/<app>`.
This file lists names, never values. `scripts/import-secrets.sh` copies the values from
the live VMs (piped over SSH straight into `vault kv put|patch <path> <key>=-`) and checks
each one by SHA-256. Rerun it any time: matching keys are left alone, a different value is
refused unless `--force`, and `--verify` only compares.

Ansible reads these paths with the `ansible-read` policy (`kv/data/homelab/*`).
`kv/homelab/site` (site addresses, domain, MACs) is described in `site/site.example.yml`.

## Created by the roles

Generated or created by Ansible and piped straight into Vault (never displayed or written to
a file). Each write is checked by reading the SHA-256 digests back (`scripts/vault-kv-digests.sh`).

| Vault path | Key | Created by | What it is for |
|---|---|---|---|
| `kv/homelab/ragnarok/filestash` | `s3_access_key`, `s3_secret_key` | `make ceph` (ceph_single: RGW user `filestash`) | Read-only S3 user Filestash browses the gateway with |
| `kv/homelab/ragnarok/filestash` | `admin_password` | `make vm HOST=ragnarok` (filestash role, `openssl rand`) | Filestash login (user `admin`) and admin console; stored as a bcrypt hash in Filestash's config |
| `kv/homelab/ragnarok/threadfin` | `admin_password` | `make vm HOST=ragnarok` (iptv role, `openssl rand`) | Threadfin web UI login (user `admin`); stored as Threadfin's HMAC hash in its `authentication.json` |

## Pending (user)

| Vault path | Key | What it is for | Who creates it |
|---|---|---|---|
| `kv/homelab/pve/netbird` | `setup_key` | NetBird enrolment of the Proxmox host | operator: reusable setup key from the NetBird dashboard |
| `kv/homelab/netbird/netbird` | `setup_key` | NetBird enrolment of the netbird VM (the netbird_peer role reads it only for a client that needs a login) | operator: reusable setup key from the NetBird dashboard |

Setup keys cannot be read back from an enrolled client, so these are new keys, written with
`vault kv put -mount=kv homelab/<path> setup_key=-` (value on stdin).

## Not imported

- No secret in config: frigate (mosquitto, gotify, nginx, homeassistant), netbird (ntfy,
  redis), ragnarok (ARR stack, qbittorrent, jackett, flaresolverr, iptv-epg).
- App data (user databases, app config directories) stays with each app.
- NetBird client state: a rebuilt host enrols again with a setup key.
